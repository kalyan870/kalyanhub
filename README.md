## Live experience

**[Visit KalyanHub →](https://kalyanhub.netlify.app)**

KalyanHub presents AI engineering work, learning progress, selected projects, posts, courses, certificates, and professional links in one public-facing space.

## Highlights

- A curated portfolio of AI engineering, GenAI, LLM, API, computer-vision, and full-stack projects
- A public learning archive for technical notes, workshops, and professional development
- Project links that connect visitors to demos and source repositories
- A credentials section with external certificate verification links
- Responsive, public portfolio experience hosted on Netlify

## Repository status

This repository currently contains KalyanHub’s public project overview, demo video, and license. The website source code is **not present in the tracked repository history**, so implementation-specific claims such as framework, database, authentication, or SEO configuration are intentionally not made here.

To make this repository code-review-ready, the original website source should be committed in a future update along with its `package.json`, deployment configuration, and environment-variable example. Until then, the live site and walkthrough are the appropriate references for the published experience.
