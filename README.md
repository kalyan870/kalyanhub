# KalyanHub

A modern personal learning and portfolio hub for building in public.

## Live website

- **Production:** [kalyanhub.netlify.app](https://kalyanhub.netlify.app)
- **Vercel deployment:** [kalyanhub.vercel.app](https://kalyanhub.vercel.app)

## What is included

- Dashboard with learning and portfolio overview
- Posts with professional summaries and highlights
- Project portfolio with live demos and source links
- Course library with lessons and progress tracking
- Certificate showcase with preview and source links
- Profile, skills, experience, and social links
- Admin workspace and settings
- Responsive layout for desktop and mobile
- Public SEO metadata, robots.txt, sitemap, and Google Search Console verification

## Technology

- React
- Vite
- Supabase integration
- Netlify and Vercel deployment configuration

## Local development

```bash
npm install
npm run dev
```

Build for production with:

```bash
npm run build
```
